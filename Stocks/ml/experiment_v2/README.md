# AI 股票預測 第二輪驗證（2026-07-23）

延續 `ml/local_run_20260714/`（第一輪：6檔股票、約1年資料、LightGBM 3分類，
結論「打不贏天真基準線」）。這輪把資料規模、標的定義、標籤方式都加大/改良，
想確認第一輪的負面結論是資料不足造成的假陰性，還是問題本質如此。

## 這輪改了什麼

1. **資料**：22檔台股權值股（`ml/config.py` SEED_SYMBOLS，扣除 0050/0056 兩檔 ETF）
   × 5年日線（2021-07 ~ 2026-07，經 yfinance），取代原本 6檔 × 1年。
2. **預測標的**：改成「相對加權指數（^TWII）的超額報酬」，而非絕對報酬——
   排除大盤同漲同跌的雜訊，讓模型只需要學個股相對強弱。
3. **標籤門檻**：漲/跌/平盤的死區改成每檔股票、每天依「過去20日波動度」
   動態調整（`0.5 × ret_std20 × sqrt(h)`），取代原本全市場統一的固定 ±0.5%/±1.2%。
4. **同時評估兩種框架**：
   - 分類（漲/跌/平盤三分類）——沿用第一輪的評估方式，方便比較。
   - 回歸（連續超額報酬）——用 Spearman rank IC（跨股排名相關性）+
     三分位多空價差回測，這是量化界評估「訊號有沒有用」的標準做法，
     比三分類準確率更敏感、更不會被死區門檻的選擇誤導。
5. **驗證期間拉長**：18個月的月度滾動樣本外測試（2025-01 ~ 2026-06），
   取代原本只有4個月，統計上更站得住腳。

程式碼：`fetch_data.py`（抓資料，快取到 `data/`）、`run_experiment.py`
（特徵/標籤/訓練/驗證一條龍）、`results_v2.json`（完整數字）。

## 結果

| 指標 | 隔日 (h=1) | 5日 (h=5) |
|---|---|---|
| 分類準確率 | 40.6%（輸給「永遠猜多數類別」基準線 41.8%）| 38.6%（輸給基準線 41.9%）|
| 方向命中率（僅看模型主動判斷多空的樣本）| 48.8%，CI (47.2%, 50.3%) — 統計上等同丟硬幣 | 52.0%，CI (50.6%, 53.5%) — 勉強顯著優於丟硬幣 |
| Spearman rank IC | **0.063，t=4.29（n=323天，顯著）** | 0.008，t=0.55（不顯著）|
| 三分位多空價差 | **0.19%/天，t=2.71（顯著）** | 0.07%/5天，t=0.36（不顯著）|

## 結論

1. **「預測單一個股明天/未來5天漲跌」這個框架，兩輪實驗都不成立。**
   分類準確率贏不了基準線，方向命中率統計上等同亂猜。資料量、標籤方式、
   市場中性化都已經改良過，結果仍然一致——這比較像是問題本質難（效率
   市場下，短線個股方向確實難predict），不是實驗做得不夠精細。

2. **但發現一個新東西**：把問題換成「跨股排名」而非「單股方向」，隔日
   （h=1）有統計上真實存在、但很小的訊號（IC≈0.06，t值4.29，323個交易日
   一致存在）。放到5天就完全消失（IC≈0，不顯著），推測是排名訊號本來
   就短命，或是5日標籤的視窗重疊造成雜訊蓋過訊號。

3. **這個排名訊號不足以支撐一個對外的功能**：IC 0.06 屬於業界認定「弱但
   真實」的訊號量級，通常需要在數百檔股票的大池子、經過交易成本估算的
   投組建構才有機會轉成實際報酬；在22檔股票、每天調倉的簡化回測下，
   0.19%/天的毛價差很可能被證交稅(0.3%)+手續費吃光，不能直接當成
   「這樣操作會賺錢」的證據。

**決定（2026-07-23）：不上線「AI 預測股票漲跌」這個功能。**
`backend/ml_predict.py`、`backend/indicators.py`、`feature_schema.py`、
`tw_market_data.py`、`chart_render.py`、`pattern_catalog.py`、`yolo_onnx.py`
及 `ml/` 下的程式碼保留作為研究紀錄（`ml_predict.py` 的端點在模型檔缺席時
本來就會誠實回報「尚未訓練/發布」，不會對外顯示假預測），但不會接上前端、
不會作為產品功能推出，避免误導用戶做投資判斷。若未來要重啟，較有希望的
方向是「跨股相對強弱排名」而非「單股方向預測」，且需要更大的股票池與
交易成本模型才值得認真評估。
