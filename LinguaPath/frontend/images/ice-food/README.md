# Ice food picture cards

1. Copy the pictures from `C:\Users\roy\Downloads\ice food` into this folder.
2. Name each file after its English word, e.g. `ice-cream.jpg`, `shaved-ice.png`, `popsicle.webp`.
3. From `LinguaPath/frontend`, run `node scripts/build-image-vocab.mjs ice-food`.
4. Optional: open `manifest.json` and fill `zh` (Chinese meaning) and `example` (sentence) for each card.

The cards show up on the Vocabulary page under **Picture Cards** and **Picture Match**.
